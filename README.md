# Smart Study Planner

Smart Study Planner is a mobile-friendly website that helps students organize assignments, manage deadlines, track course grades, and decide what to work on first. Its library-inspired design provides a clear, welcoming space for planning schoolwork and everyday tasks.

## Features

- **Home dashboard:** See upcoming work and assignment priorities based on deadlines, difficulty, and estimated effort.
- **Interactive calendar:** Browse deadlines by date and add assignments to a selected day.
- **Courses and grades:** Link assignment scores to courses and automatically calculate points-based course averages.
- **Pass forecasts:** Estimate final course performance and the average needed on remaining work to reach a chosen passing grade.
- **Assignment management:** Create, edit, search, complete, and delete assignments.
- **Personal to-do list:** Organize tasks for school, work, and daily life.
- **Responsive design:** Use the planner on desktop and mobile screens.

## Built With

HTML, CSS, and vanilla JavaScript. Planner data is saved in the current browser using localStorage.

## Current Scope

Grades and forecasts use points-based calculations; weighted grading categories are not supported yet. Forecasts are estimates based on entered scores and course settings, not guarantees of passing. Data does not sync across devices, and this static repository does not include a backend or account authentication. The separate ChatGPT Sites deployment provides its own platform-managed sign-in.
